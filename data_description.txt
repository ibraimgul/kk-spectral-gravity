# SPARC Galaxy Data Description

## Overview
This directory contains rotation curve data for 118 high-quality galaxies from the SPARC (Spitzer Photometry and Accurate Rotation Curves) database.

**Reference:** Lelli et al. 2016, AJ 152, 157  
**DOI:** https://doi.org/10.3847/0004-6256/152/6/157  
**Original Data:** http://astroweb.cwru.edu/SPARC/

## Selection Criteria

The sample was selected using the following cuts:
1. **Quality flag Q = 1**: Highest reliability in photometry and kinematics
2. **Inclination i > 40°**: Minimize deprojection uncertainties
3. **Distance uncertainty σ_D/D < 0.25**: Reliable distance measurements

This yields **118 galaxies** spanning:
- Stellar mass: 10^8 - 10^11 M☉
- Maximum radius: 1 - 50 kpc
- Morphologies: Spirals (Sa-Sd), irregulars, dwarfs

## File Format: sparc_q1_i40.csv

### Columns

| Column | Unit | Description |
|--------|------|-------------|
| `Galaxy` | - | Galaxy name (e.g., NGC2403) |
| `Rad` | kpc | Galactocentric radius |
| `Vobs` | km/s | Observed circular velocity |
| `e_Vobs` | km/s | Velocity uncertainty |
| `Vgas` | km/s | Gas contribution (HI + He) |
| `Vdisk` | km/s | Stellar disk contribution (3.6μm) |
| `Vbul` | km/s | Bulge contribution (if present) |
| `SBdisk` | L☉/pc² | Disk surface brightness at 3.6μm |
| `SBbul` | L☉/pc² | Bulge surface brightness (if present) |
| `Inc` | deg | Inclination angle |
| `Distance` | Mpc | Galaxy distance |
| `e_Distance` | Mpc | Distance uncertainty |

### Velocity Components

The total baryonic velocity is computed as:

```
V_bar² = V_gas² + (Υ★ · V_disk)² + (Υ★ · V_bul)²
```

where Υ★ is the stellar mass-to-light ratio in [3.6] band (free parameter).

### Gas Contribution

- **HI:** From 21cm line observations
- **He correction:** Helium abundance factor (typically 1.33)
- **H₂:** Included for galaxies with CO detections

### Stellar Contribution

- **Disk:** Computed from 3.6μm surface photometry using IRAC/Spitzer
- **Bulge:** Sérsic profile fit (n=1-4) for early-type spirals
- **M/L prior:** Log-normal with μ=0.47, σ=0.10 (McGaugh & Schombert 2014)

## Data Quality Flags (Original SPARC)

| Flag | Meaning |
|------|---------|
| Q=1  | Best quality: high S/N, good beam smearing correction |
| Q=2  | Good quality: minor beam smearing or moderate S/N |
| Q=3  | Acceptable: significant uncertainties |

**This sample uses Q=1 only.**

## Systematics

### Main Uncertainties

1. **Distance errors:** Median σ_D/D ≈ 15% (Tully-Fisher or Cepheid-based)
2. **Inclination:** Typically σ_i ≈ 5°, but assumes axisymmetry (ignores bars, warps)
3. **M/L ratio:** Population synthesis models have ~30% systematic uncertainty
4. **Pressure support:** Negligible for rotation-dominated galaxies (V/σ > 5)
5. **Non-circular motions:** Radial flows, spiral arms (~5-10 km/s)

### Systematic Floor

We adopt a systematic velocity floor: **σ_sys = 5 km/s** (added in quadrature)

```python
sigma_total = sqrt(e_Vobs^2 + sigma_sys^2)
```

## Usage Example

```python
import pandas as pd
import numpy as np

# Load data
df = pd.read_csv('sparc_q1_i40.csv')

# Select a galaxy
galaxy = df[df['Galaxy'] == 'NGC2403']

# Extract rotation curve
R = galaxy['Rad'].values  # kpc
V_obs = galaxy['Vobs'].values  # km/s
sigma_V = galaxy['e_Vobs'].values  # km/s

# Compute baryonic contribution (assuming Υ★ = 0.5)
Upsilon_star = 0.5
V_gas = galaxy['Vgas'].values
V_disk = galaxy['Vdisk'].values
V_bul = galaxy['Vbul'].fillna(0).values

V_bar = np.sqrt(V_gas**2 + (Upsilon_star * V_disk)**2 + (Upsilon_star * V_bul)**2)

# Radial acceleration
g_obs = V_obs**2 / R  # m/s^2 (multiply by 1e3^2 / 3.086e19)
g_bar = V_bar**2 / R
```

## Data Provenance

### Original SPARC Sample (Lelli et al. 2016)
- Total galaxies: 175
- Quality flags: Q=1 (83), Q=2 (62), Q=3 (30)

### This Subsample
- Galaxies: 118
- Criteria: Q=1, i>40°, σ_D/D<0.25
- Total data points: ~3600 (varies per galaxy)

### Data Processing
1. Downloaded from SPARC website (ASCII format)
2. Converted to CSV
3. Applied quality cuts
4. Added distance uncertainties from literature
5. Computed galactocentric radii using distance and position angle
